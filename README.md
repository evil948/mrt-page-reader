# MRT+ — озвучка страниц голосами Яндекса

Userscript для [Tampermonkey](https://www.tampermonkey.net/): читает открытую статью голосами Yandex TTS (Zahar, Ermil, Oksana и др.) **прямо во вкладке** — без панели MRT и без лишнего клика «Старт».

| | |
| --- | --- |
| **Горячая клавиша** | `Alt+R` |
| **Браузеры** | Firefox, Chrome, Яндекс.Браузер (+ Tampermonkey) |
| **Версия** | 1.6.14 |

## Установка

1. Установите [Tampermonkey](https://addons.mozilla.org/firefox/addon/tampermonkey/) (или аналог).
2. Откройте скрипт:

   **[➜ Install mrt-page-reader.user.js](https://raw.githubusercontent.com/evil948/mrt-page-reader/main/mrt-page-reader.user.js)**

3. Подтвердите установку в Tampermonkey.
4. Обновите страницу статьи (`F5`) и нажмите **Озвучить** или `Alt+R`.

Обновления подтягиваются сами (`@updateURL` / `@downloadURL` указывают на этот репозиторий).

## Возможности

- Достаёт текст статьи (заголовок, абзацы, подзаголовки, короткие реплики)
- Голоса Яндекса с выбором в кнопке рядом с «Озвучить»
- Подсветка текущего фрагмента и оценка оставшегося времени
- Пауза / продолжение / стоп
- Озвучка выделенного текста (меню Tampermonkey)
- Предзагрузка следующего блока во время воспроизведения — почти без паузы между кусками
- Компактная кнопка ▶ в углу; полное меню открывается по клику (и при озвучке)

## Управление

| Действие | Как |
| --- | --- |
| Открыть / свернуть меню | маленькая кнопка ▶ / × |
| Старт / пауза / продолжение | кнопка или `Alt+R` |
| Стоп | ■ Стоп |
| Смена голоса | выпадающий список в меню |
| Только выделение | меню TM → «Озвучить выделенное» |

## Как это работает

Скрипт использует тот же канал синтеза, что и [MRT](https://alkohole.github.io/machine-reading-text/) (Yandex Uniproxy / SpeechKit), но проигрывает Ogg Opus **на самой странице**. Поэтому жест «Озвучить» / `Alt+R` сразу разрешает звук — отдельное окно и клик «Старт» не нужны.

## Устранение проблем

- **Нет звука / ошибка TTS** — обновите скрипт до последней версии, перезагрузите вкладку, попробуйте другой голос.
- **Голоса вроде Levitan** — в списке только те, что реально отвечают через Uniproxy; часть старых id MRT сейчас недоступна.
- **Не тот текст** — уберите случайное выделение мышью или используйте «Озвучить выделенное» намеренно.
- **Два скрипта сразу** — удалите старую локальную копию MRT+, оставьте одну установленную из GitHub.
